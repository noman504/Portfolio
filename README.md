# Noman Portfolio — React + Vite

## Run locally

```bash
npm install
npm run dev
```

## Required image

Copy your photo to `public/image/pf.png` (transparent PNG, person cut out).

## Deploy on Vercel

1. Push this folder to GitHub.
2. On vercel.com choose **Add New → Project** and import the repo.
3. Vercel detects Vite automatically. Keep the defaults:
   - Build command: `npm run build`
   - Output directory: `dist`
4. Click **Deploy**.

Or with the CLI: `npm i -g vercel` then `vercel --prod`.
